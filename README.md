# Japanese Image Layout Translator

This repository-local Skill rebuilds Japanese source images as Chinese PNGs while using a supplied image as the layout reference.

The current scaffold defines the execution contract and bounded correction loop. It deliberately does not install image dependencies or include private test images. Add the OCR, Pillow, and OpenCV executors only after the contract is approved.

The intended public repository should include dependency instructions, reproducible examples, and a license before publishing.
