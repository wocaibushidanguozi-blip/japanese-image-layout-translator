# Japanese Image Layout Translator

This repository-local Skill rebuilds Japanese source images as Chinese PNGs while using a supplied image as the layout reference.

The current repository contains the execution contract, bounded correction loop, OCR helper, local image dependencies, and reusable layout profiles. Private test images remain local and are not included in the public repository.

The analyzed sample set is documented as optional prior knowledge in `references/sample-experiences.md`. It is read only when a new page resembles a recorded scan type; it is not required for every run.

The intended public repository should include dependency instructions, reproducible examples, and a license before publishing.
